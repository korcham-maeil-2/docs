## 2. 인증키

- **키 값은 이 문서와 저장소에 적지 않는다.** `backend/.env`에만 두고 팀원끼리 직접 전달한다.

## 4. 훈련과정 목록 요청 변수 (두 API 공통)

| 이름 | 필수 | 월급지도에서 쓰는 값 | 설명 |
|---|---|---|---|
| `authKey` | 필수 | (해당 서비스 키) | |
| `returnType` | 필수 | `JSON` | `XML` / `JSON` |
| `outType` | 필수 | `1` | `1` 목록, `2` 상세 |
| `pageNum` | 필수 | `1`~ | 최대 1000 |
| `pageSize` | 필수 | `100` | 최대 100. **101 이상이면 결과가 비어 온다** |
| `srchTraStDt` | 필수 | 오늘 (`YYYYMMDD`) | 훈련 **시작일** 범위 From |
| `srchTraEndDt` | 필수 | 오늘 + 3개월 | 훈련 **시작일** 범위 To (종료일이 아님) |
| `sort` | 필수 | `ASC` | |
| `sortCol` | 필수 | `2` | 1 기관명, 2 훈련시작일, 3 취업률, 5 만족도 |
| `srchTraArea1` | 선택 | `lawd_cd` 앞 2자리 | 시도 (5절 참고) |
| `srchTraArea2` | 선택 | `lawd_cd` 5자리 | 시군구 |
| `crseTracseSe` | 선택 | 내일배움카드 `C0061I` / 컨소시엄 `C0042` | 훈련유형 |
| `srchTraGbn` | 선택 | `M1001` | 훈련구분. `M1001` 일반(집체·오프라인), `M1005` 인터넷, `M1010` 혼합, `M1014` 스마트혼합 |
| `wkendSe` | 선택 | `1` (주말반만 볼 때) | 1 주말, 2 주말·주중 혼합, 3 주중, 9 해당없음 |
| `srchNcs1`~`4` | 선택 | — | NCS 직종 분류 |
| `srchTraProcessNm`, `srchTraOrganNm` | 선택 | — | 과정명·기관명 검색 |

훈련유형(`crseTracseSe`) 중 재직자에게 의미 있는 값:

| API | 값 | 뜻 |
|---|---|---|
| 내일배움카드 | `C0061I` | 국민내일배움카드 (주 훈련대상: **재직자**) |
| 내일배움카드 | `C0061S` | 국민내일배움카드 (주 훈련대상: 구직자) — 쓰지 않음 |
| 내일배움카드 | `C0031` | 근로자 원격훈련 — 온라인이라 쓰지 않음 |
| 컨소시엄 | `C0042` | 국가인적자원개발컨소시엄 (결과에 `C0042C` 대중소 공동훈련도 함께 나옴) |
| 컨소시엄 | `C0042C`, `C0066`, `C0098` | 대중소 공동훈련, 지역산업맞춤형, 산업계주도 청년맞춤형 |

- 사업주훈련은 회사가 직원을 보내는 과정이라 개인이 고르기 어려워 신청하지 않았다.

## 5. 지역 코드 — **명세 표를 쓰지 말 것**

- 명세 표에는 전북이 `45`로 적혀 있지만 **`45`로 조회하면 0건**, `52`로 조회해야 나온다 (전북특별자치도 코드 변경이 명세에 반영 안 됨). 공통코드 API도 전북을 `52000`으로 준다.
- **시군구 코드(`srchTraArea2`, 응답의 `trngAreaCd`)는 `backend/data/lawd_codes.csv`의 `lawd_cd`와 같다.** 실거래가와 훈련과정이 지역 코드표 하나로 된다.
  - 시도 = `lawd_cd[:2]`, 시군구 = `lawd_cd`
  - 확인한 예: 부산 해운대구 `26350`, 전북 전주시 덕진구 `52113`, 전남광주 북구 `12300`, 경북 구미시 `47190`, 경기 수원시 영통구 `41117`, 강원 춘천시 `51110` — 모두 해당 지역 과정만 나옴
  - 세종은 시도 `36`, 시군구 `36110`

## 6. 응답 (목록, JSON)

```json
{
  "scn_cnt": 29, "pageNum": "1", "pageSize": "1",
  "srchList": [ { ...과정 1건... } ]
}
```

- `returnType=XML`이면 최상위가 `<HRDNet>`이고 과정은 `<srchList><scn_list>…</scn_list></srchList>`.
- 숫자도 문자열로 온다. 빈 값은 `""`.

| 필드 | 뜻 | 월급지도 사용 |
|---|---|---|
| `title` | 과정명 | 화면 표시 |
| `subTitle` | 훈련기관명 | 화면 표시 |
| `titleLink` | 고용24 과정 상세 페이지 | "신청하러 가기" 링크 |
| `subTitleLink` | 고용24 기관 페이지 | |
| `traStartDate`, `traEndDate` | 훈련 시작·종료일 (`YYYY-MM-DD`) | 화면 표시, 플랜 월 배치 |
| `trngAreaCd` | 훈련 지역 시군구 코드 | **지역 판단 기준** |
| `address` | 주소 (시도 시군구까지) | 참고만 (7절) |
| `wkendSe` | 주말/주중 | "주말반" 배지 |
| `realMan` | 실제 훈련비(원) | |
| `courseMan` | 수강비(원) | 컨소시엄은 `0` (무료) |
| `yardMan`, `regCourseMan` | 정원, 수강신청 인원 | 마감 임박 표시 가능 |
| `stdgScor` | 만족도 점수 | |
| `ncsCd` | NCS 코드 | 직무 매칭 시 |
| `trainTarget`, `trainTargetCd` | 훈련유형 | **재직자 여부 판단에 쓰지 말 것** (7절) |
| `trprId`, `trprDegr` | 과정 ID, 회차 | 캐시 키 |
| `telNo`, `instCd`, `trainstCstId`, `titleIcon` 등 | 기타 | 사용 안 함 |

### 요청 예시 (키 제거)

```
GET https://www.work24.go.kr/cm/openApi/call/hr/callOpenApiSvcInfo310L01.do
    ?authKey=<KEY>&returnType=JSON&outType=1&pageNum=1&pageSize=100
    &srchTraStDt=20261111&srchTraEndDt=20270228&sort=ASC&sortCol=2
    &srchTraArea1=26&srchTraArea2=26350&crseTracseSe=C0061I&srchTraGbn=M1001
```

## 7. 실제 호출로 알게 된 주의점

| 내용 | 근거 | 처리 |
|---|---|---|
| 재직자 필터는 동작하지만 응답 `trainTargetCd`는 `C0061`(일반)로 옴 | 서울: 필터 없음 6,126 / `C0061I` 3,530 / `C0061S` 1,489건, 결과는 모두 `C0061` | 재직자 여부는 **요청 조건으로만** 구분 |
| 컨소시엄 `address`는 기관 주소로 보임 | 경기 조회 100건 중 19건이 "서울 강서구 대한상공회의소 서울기술교육센터" 등. `trngAreaCd`는 항상 조회 지역과 일치 | 지역은 `trngAreaCd`로 판단, 화면에서는 상세 링크로 장소 확인 안내 (추정이므로 시연 전 몇 건 직접 확인) |
| 전북 코드 `45` 0건 | 5절 | `52` 사용 |
| `pageSize` 101 이상이면 빈 결과 | | 100으로 고정하고 `scn_cnt`로 페이지 반복 |
| `srchTraStDt`를 빼도 오류 없이 결과가 옴 | | 필수 값은 코드에서 항상 채움 |

### 오류 형식

| 상황 | 응답 |
|---|---|
| 키가 틀림 / **다른 서비스의 키** | `{"error": "신청하신 OpenApi 서비스가 존재하지 않습니다"}` |

- 정상 응답에는 `error` 키가 없다. 응답에 `error`가 있으면 오류로 처리하고 로그를 남긴다.

## 9. 공통코드 (지역)

- 요청: `authKey`, `returnType=XML`(명세상 xml 필수), `target=CMCD`, `dtlGb=1`(지역). 2 직종, 3 자격면허, 6 전공 등
- 응답: `<cmcdRegion><total>285</total>` 아래 `<oneDepth>`(시도) → `<twoDepth>`(시군구, `superCd`=상위 코드)
- 시도는 `11000`, `52000`처럼 5자리, 세종은 `36110`
- 월급지도에서는 `lawd_codes.csv`로 충분해서 **코드가 바뀌었는지 점검할 때만** 쓴다.

## 10. 월급지도에서 쓰는 방법 (설계)

1. 사용자가 고른 근무지 → `lawd_cd` → `srchTraArea1`(앞 2자리), `srchTraArea2`(5자리)
2. 두 API를 같은 조건으로 조회: 시작일 오늘~3개월, `srchTraGbn=M1001`(오프라인)
   - 내일배움카드: `crseTracseSe=C0061I`
   - 컨소시엄: `crseTracseSe=C0042` (무료, 중소기업 재직자)
3. 주말반(`wkendSe=1`)을 우선 보여 주고, 직무가 정해졌으면 NCS 대분류로 좁힌다
4. 결과는 SQLite에 하루 단위 캐시 (1일 1만 쿼리 미만 약관)
5. 화면: 과정명·기관·기간·주말반 여부·수강비 + `titleLink`. 출처 "고용24", 신뢰도 **확인**(공공 API). 실제 수강 자격(재직 여부, 내일배움카드 발급, 컨소시엄 참여기업 소속 등)은 사용자가 상세 페이지에서 확인하도록 안내
