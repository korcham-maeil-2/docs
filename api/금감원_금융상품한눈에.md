# 금융감독원 금융상품 한눈에 API (적금 / 정기예금)

> 관련 이슈: korcham-maeil-2/docs#1
> 사용처: 잔여액(월급 − 고정지출)으로 넣을 수 있는 적금·예금 상품 추천 — 노드 이름·설계는 팀 논의 후 확정
> 명세 출처: [금융상품 한눈에 오픈API 개발가이드](https://finlife.fss.or.kr/finlife/main/contents.do?menuNo=700029) + 실제 호출 결과 (2026-11-11, 은행 권역 `020000`, 2026년 10월 공시분으로 확인). 공개 페이지에 없는 내용은 실제 응답으로 확인한 값만 적었다.

## 1. 발급 현황

| API | 상세 페이지 | 상태 | 이용형태 | 신청일 | 만료 |
|---|---|---|---|---|---|
| 적금 | [700053](https://finlife.fss.or.kr/finlife/api/fdrmEntyApi/list.do?menuNo=700053) | 발급 완료 (호출 확인) | 개인 | 2026-11-11 | 만료일 없음. 12개월 미사용 시 삭제 (약관 제7조 6항) |
| 정기예금 | [700052](https://finlife.fss.or.kr/finlife/api/fdrmDpstApi/list.do?menuNo=700052) | 발급 완료 (호출 확인) | 개인 | 같은 키 | 같은 키 |

- 개인 인증키는 **신청 즉시 발급**된다 (인증키 신청 페이지 기재). 키 하나로 이 사이트의 모든 상품 API를 부른다.
- 같은 키로 주택담보대출·전세자금대출·개인신용대출·개인사업자대출·금융회사 API도 부를 수 있다 (8절). 연금저축은 통합연금포털로 이관되어 이 키로는 안 된다.
- 일일 호출: 개인 키 **1일 10,000건** (약관 제7조 4항). 초과하면 `err_cd` `020`.
- 비용: 무료 / 형식: JSON·XML / REST (GET)

## 2. 인증키

- **키 값은 이 문서와 어떤 저장소에도 적지 않는다.** `backend/.env`에만 두고, 팀원에게는 디스코드 채팅으로 전달한다.
- 키는 영문·숫자 **32자리**다.
- 키 확인 위치: 금융상품 한눈에 → 오픈API → 인증키 신청 → 신청결과 확인 (재전송도 같은 메뉴)
- 약관상 1인 1개만 발급되고 제3자에게 양도할 수 없다 (제5조). 팀에서는 이 키 하나를 서버에서만 쓴다.

```dotenv
# backend/.env (커밋 금지 — 형식은 backend/.env.example 참고)
FINLIFE_API_KEY=<32자리 인증키>
```

## 3. 엔드포인트

`{형식}` 자리에 `json` 또는 `xml`을 넣는다. 가이드에는 `http://`로 적혀 있지만 **`https://`도 정상 동작한다** (실제 호출 확인). 키가 URL에 실리므로 `https`를 쓴다.

| 상품 | 요청 URL |
|---|---|
| 적금 | `https://finlife.fss.or.kr/finlifeapi/savingProductsSearch.{형식}` |
| 정기예금 | `https://finlife.fss.or.kr/finlifeapi/depositProductsSearch.{형식}` |

## 4. 요청 변수 (모든 상품 공통)

| 변수 | 필수 | 설명 / 값 |
|---|---|---|
| `auth` | 필수 | 인증키 (32자리) |
| `topFinGrpNo` | 필수 | 권역 코드: `020000` 은행, `030200` 여신전문, `030300` 저축은행, `050000` 보험, `060000` 금융투자 |
| `pageNo` | 필수 | 페이지 번호 (1부터) |
| `financeCd` | 선택 | 금융회사 코드 또는 이름 일부 (예: `국민` → 국민은행 상품만) |

실제 호출로 확인한 것 (2026-11-11, 적금 기준):

| 권역 | `total_count` | `max_page_no` | 비고 |
|---|---|---|---|
| `020000` 은행 | 60 | 1 | |
| `030300` 저축은행 | 278 | 3 | 한 페이지 최대 100건 → **페이지를 돌며 모아야 한다** |
| `050000` 보험 / `060000` 금융투자 | 0 | 1 | 적금 상품 없음 |

## 5. 응답

### 공통 구조 (JSON)

```text
result
├─ prdt_div       상품 구분 (적금 S, 정기예금 D)
├─ total_count    전체 상품 수
├─ max_page_no    전체 페이지 수
├─ now_page_no    현재 페이지
├─ err_cd         응답 코드 ("000" = 정상, 6절)
├─ err_msg        응답 메시지 ("정상")
├─ baseList[]     상품 기본정보 — 상품 1개당 1행
└─ optionList[]   금리 옵션 — 상품 1개에 여러 행 (기간·적립방식별)
```

- `baseList`와 `optionList`는 **`fin_co_no` + `fin_prdt_cd`로 묶는다.** 은행 적금은 상품 60개에 옵션 181행이었다.
- 숫자 타입이 섞여 온다: `intr_rate`는 `2.45`(float)와 `3`(int)이 섞이고, `max_limit`은 숫자 또는 `null`(한도 없음, 60개 중 15개)이다.
- 실패 응답에는 `total_count`가 문자열 `"0"`으로 오고 `baseList`가 없다.

### 필드 — `baseList` (적금·정기예금 같음)

| 필드 | 뜻 | 실제 값 예 |
|---|---|---|
| `dcls_month` | 공시 제출월 | `"202610"` |
| `fin_co_no` | 금융회사 코드 | `"0010001"` |
| `kor_co_nm` | 금융회사 이름 | `"우리은행"` |
| `fin_prdt_cd` | 상품 코드 | `"WR0001F"` |
| `fin_prdt_nm` | 상품 이름 | `"우리SUPER주거래적금"` |
| `join_way` | 가입 방법 (쉼표 구분) | `"영업점,인터넷,스마트폰,전화(텔레뱅킹)"` |
| `mtrt_int` | 만기 후 이자율 (자유 서술, 줄바꿈 포함) | |
| `spcl_cnd` | 우대 조건 (자유 서술) | |
| `join_deny` | 가입 제한: `1` 제한 없음, `2` 서민 전용, `3` 일부 제한 | 은행 적금: `1` 56개, `3` 4개 |
| `join_member` | 가입 대상 | `"실명의 개인"` |
| `etc_note` | 기타 유의사항 (가입 기간·금액 등) | |
| `max_limit` | 최고 한도 (원) | 숫자 또는 `null` |
| `dcls_strt_day` / `dcls_end_day` | 공시 시작일 / 종료일 (`YYYYMMDD`) | `"20261020"` / `null` (종료일 없음) |
| `fin_co_subm_day` | 금융회사 제출일 (`YYYYMMDDHH24MI`) | `"202610201420"` |

### 필드 — `optionList`

| 필드 | 뜻 | 실제 값 |
|---|---|---|
| `fin_co_no`, `fin_prdt_cd`, `dcls_month` | `baseList`와 묶는 키 | |
| `intr_rate_type` / `intr_rate_type_nm` | 금리 유형 | `S` 단리 (169행), `M` 복리 (12행) |
| `rsrv_type` / `rsrv_type_nm` | 적립 유형 (**적금만**) | `S` 정액적립식 (47행), `F` 자유적립식 (134행) |
| `save_trm` | 저축 기간 (개월, **문자열**) | `"1"`, `"3"`, `"6"`, `"12"`, `"24"`, `"36"` |
| `intr_rate` | 기본 금리 (연 %) | `2.45` |
| `intr_rate2` | 최고 우대 금리 (연 %) | `3.85` |

### Python 호출 예시

```python
import httpx

BASE = 'https://finlife.fss.or.kr/finlifeapi'


def fetch_savings(api_key: str, top_fin_grp_no: str = '020000') -> tuple[list, list]:
    """권역 하나의 적금 상품을 모든 페이지에서 모은다."""
    base_list, option_list = [], []
    page = 1
    while True:
        r = httpx.get(
            f'{BASE}/savingProductsSearch.json',
            params={'auth': api_key, 'topFinGrpNo': top_fin_grp_no, 'pageNo': page},
            timeout=10,
        )
        r.raise_for_status()
        result = r.json()['result']
        if result['err_cd'] != '000':
            raise RuntimeError(f"finlife {result['err_cd']}: {result['err_msg']}")
        base_list += result['baseList']
        option_list += result['optionList']
        if page >= int(result['max_page_no']):
            return base_list, option_list
        page += 1
```

## 6. 오류

오류여도 **HTTP 상태는 200**이다. 반드시 `err_cd`를 확인한다.

| `err_cd` | `err_msg` | 뜻 |
|---|---|---|
| `000` | 정상 | |
| `010` | 미등록 인증키 | |
| `011` / `012` | 중지된 / 삭제된 인증키 | |
| `013` | 샘플 인증키 | 실제 호출에서 형식만 맞는 임의 32자 키를 넣었을 때도 이 코드가 왔다 |
| `020` | 일일검색 허용횟수 초과 | 개인 키 1일 10,000건 |
| `021` | 허용된 IP가 아닙니다 | 단체 키 전용 |
| `100` | `{변수} 누락` | 실제 확인: `topFinGrpNo` 빼면 `"topFinGrpNo 누락"` |
| `101` | `{변수}의 부적절한 값` | |
| `900` | 정의되지 않은 오류 | 서버 내부 오류 |

## 7. 이용 조건 (발표·소개서 대비)

- **저장 제한**: 약관 제9조 3항에 "실시간 제공 정보는 서비스와 연동만 가능하며 복제·저장·전송할 수 없다"는 취지가 있다. → DB에 쌓아 두지 말고 요청할 때 불러오거나, 캐시를 두더라도 짧게 두는 방향을 팀에서 정해야 한다.
- **출처 표기 의무**: 화면에 "금융상품통합비교공시시스템(금융감독원) 금융회사 상품정보"를 사용했다고 표시해야 한다 (제9조 4항). 프로젝트 소개서 별첨 「활용한 외부 자원·출처」 표에도 적는다.
- **정확성 한계**: 금융회사 업무보고서 기반이라 오류가 있을 수 있고 최신성을 보증하지 않는다 (제10조 6항). 공시는 월 단위(`dcls_month`)라 실제 창구 금리와 다를 수 있다 → 화면에 "공시 기준월"과 "가입 전 은행에서 확인" 문구를 둔다.
- `spcl_cnd`(우대 조건)는 자유 서술이라 최고 금리(`intr_rate2`) 달성 조건을 기계적으로 판단하기 어렵다. 추천은 기본 금리(`intr_rate`) 기준으로 하고 우대 금리는 참고로 보여 주는 편이 안전하다.

## 8. 같은 키로 쓸 수 있는 다른 API (명세만 확인, 호출 안 함)

| 상품 | 요청 URL |
|---|---|
| 금융회사 | `https://finlife.fss.or.kr/finlifeapi/companySearch.{형식}` |
| 주택담보대출 | `…/mortgageLoanProductsSearch.{형식}` |
| 전세자금대출 | `…/rentHouseLoanProductsSearch.{형식}` |
| 개인신용대출 | `…/creditLoanProductsSearch.{형식}` |
| 개인사업자대출 | `…/busiLoanProductsSearch.{형식}` |

전세자금대출은 월세 대신 전세를 고려하는 사용자에게 쓸 수 있다. 필요해지면 실제 호출로 필드를 확인한 뒤 이 문서에 추가한다.
