# 온통청년 청년정책 API

> 관련 이슈: korcham-maeil-2/docs#1
> 사용처: 사용자 지역·나이에 맞는 청년정책(주거·금융 지원 등) 추천 — 노드 이름·설계는 팀 논의 후 확정
> 명세 출처: [온통청년 오픈(OPEN) API 제공목록](https://www.youthcenter.go.kr/cmnFooter/openapiIntro/oaiDoc) · [이용방법](https://www.youthcenter.go.kr/cmnFooter/openapiIntro/oaiGuide) + 실제 호출 결과 (2026-11-11). 공개 페이지에 없는 내용은 실제 응답으로 확인한 값만 적었다.

## 1. 발급 현황

| API | 상태 | 신청일 | 만료 |
|---|---|---|---|
| 청년정책 (`getPlcy`) | 승인 완료 (호출 확인) | 2026-11-11 (당일 승인) | 미확인 (공개 페이지에 기재 없음) |

- 온통청년 **회원 전용**이다. 로그인 → 마이페이지 → 오픈(OPEN) API에서 신청하고, **담당자 심사 후 승인**된다 ("신청 내용이 부적절하면 미승인될 수 있음").
- 일일 호출 한도·비용: 공개 페이지에 기재 없음 (미확인).
- 같은 사이트에 기본계획중점과제·기본계획정책방향·청년콘텐츠·기본계획과제·청년센터 API도 있다. 지금은 청년정책만 쓴다.
- 예전 주소 `https://www.youthcenter.go.kr/opi/youthPlcyList.do`(변수 `openApiVlak`, `display` 등)가 아직 일부 페이지에 남아 있지만, 현재 제공목록 페이지의 주소는 아래 3절 `getPlcy`다. **`getPlcy`만 쓴다.**

## 2. 인증키

- **키 값은 이 문서와 어떤 저장소에도 적지 않는다.** `backend/.env`에만 두고, 팀원에게는 디스코드 채팅으로 전달한다.
- 키는 하이픈이 포함된 **36자** 문자열이다 (UUID 형식).
- 키 확인 위치: 온통청년 로그인 → 마이페이지 → 오픈(OPEN) API

```dotenv
# backend/.env (커밋 금지 — 형식은 backend/.env.example 참고)
YOUTHCENTER_API_KEY=<36자 인증키>
```

## 3. 엔드포인트

| 기능 | 요청 URL | 메서드 |
|---|---|---|
| 청년정책 목록 / 상세 | `https://www.youthcenter.go.kr/go/ythip/getPlcy` | GET |

목록과 상세가 **같은 주소**다. `pageType`과 `plcyNo`로 구분한다 (4절).

## 4. 요청 변수

| 변수 | 타입 | 필수 | 설명 |
|---|---|---|---|
| `apiKeyNm` | String | **필수** | 인증키 |
| `pageNum` | Number | 선택 | 페이지 번호 |
| `pageSize` | Number | 선택 | 한 페이지 건수 |
| `pageType` | String | 선택 | `1` 목록 / `2` 상세 |
| `plcyNo` | String | 선택 | 정책 번호 (상세 조회 시) |
| `rtnType` | String | 선택 | `json` / `xml` |
| `plcyKywdNm` | String | 선택 | 정책 키워드. 여러 개는 쉼표: `"키워드1,키워드2"` |
| `plcyExplnCn` | String | 선택 | 정책 설명 (검색어) |
| `plcyNm` | String | 선택 | 정책 이름 (검색어) |
| `zipCd` | String | 선택 | 법정 시군구 코드 5자리, 쉼표로 여러 개. 예: `11000` 서울 전체, `11680` 강남구 |
| `lclsfNm` | String | 선택 | 정책 대분류명, 쉼표로 여러 개 |
| `mclsfNm` | String | 선택 | 정책 중분류명, 쉼표로 여러 개 |

실제 호출로 확인한 것 (2026-11-11):

| 요청 | 결과 |
|---|---|
| 조건 없음 | `totCount` **3,938** |
| `pageSize=1000` | 1,000건 한 번에 반환됨 (상한은 미확인) |
| `zipCd=11620` (관악구) | 820건 |
| `lclsfNm=주거` | 421건 |
| `plcyKywdNm=보조금` | 1,057건 |
| `rtnType` 생략 | JSON으로 응답 |
| `pageType=2&plcyNo=…` | 해당 정책 1건, `pagging` 없음 |
| `plcyNo=…` 만 | 해당 정책 1건, `pagging` 없음 |

- `zipCd`는 국토부 전월세 API의 `LAWD_CD`와 **같은 5자리 시군구 코드**다 → `backend/data/lawd_codes.csv`를 같이 쓸 수 있다.
- 대분류명에 들어간 가운뎃점은 일반 `·`(U+00B7)가 아니라 **반각 `･`(U+FF65)** 다. 예: `금융･복지･문화`, `교육･직업훈련`. 값을 직접 타이핑하면 검색이 안 될 수 있으니 응답에서 복사해 쓴다.

### 분류 필터 주의 (실제 호출로 확인, 2026-11-11)

**대분류 이름이 두 벌 섞여 있다.** 코드정의서(엑셀)의 이름과 실제 응답에 나오는 이름이 다르고, 둘 다 검색되는데 **결과 건수가 다르다** (서로 다른 정책 묶음).

| 코드정의서 이름 | 건수 | 응답에 나오는 이름 | 건수 |
|---|---|---|---|
| `일자리` | 1,491 | (같음) | |
| `주거` | 421 | (같음) | |
| `교육` | 618 | `교육･직업훈련` | 420 |
| `복지문화` | 354 | `금융･복지･문화` | 567 |
| `참여권리` | 198 | `참여･기반` | 338 |

- 빠짐없이 가져오려면 두 이름을 모두 써야 할 수 있다 (예: `복지문화,금융･복지･문화`). 쉼표로 묶었을 때 합집합이 되는지는 **아직 확인 안 함**.
- 일반 가운뎃점으로 쓴 `금융·복지·문화`는 **0건**이다.
- **띄어쓰기가 들어간 중분류명은 검색이 안 된다.** `전월세 및 주거급여 지원`, `주택 및 거주지`, `취약계층 및 금융지원` 모두 공백을 `%20`·`+` 어느 쪽으로 보내도 0건이다. 띄어쓰기 없는 `문화활동`은 294건이 나온다. → 중분류는 **대분류로 받아 온 뒤 코드에서 거른다.**
- `plcyKywdNm`을 쉼표로 여러 개 넣으면 합집합이다: `주거지원` 367건 → `주거지원,금리혜택` 440건.
- `plcyNm`(정책 이름 검색)은 띄어쓰기가 있어도 된다: `청년 월세` → 12건.

실제 응답에 나온 분류 (1,000건 표본):

| 대분류 `lclsfNm` | 건수 | 중분류 `mclsfNm` 예 |
|---|---|---|
| 일자리 | 341 | 취업, 창업 |
| 금융･복지･문화 | 249 | 취약계층 및 금융지원, 문화활동 및 생활지원, 건강, 예술인지원 |
| 교육･직업훈련 | 163 | 미래역량강화 |
| 참여･기반 | 112 | 청년참여 |
| 주거 | 108 | 전월세 및 주거급여 지원, 주택 및 거주지 |

코드정의서의 정책 키워드 17개: 대출, 보조금, 바우처, 금리혜택, 교육지원, 맞춤형상담서비스, 인턴, 벤처, 중소기업, 청년가장, 장기미취업청년, 공공임대주택, 신용회복, 육아, 출산, 해외진출, 주거지원

## 5. 응답

### 공통 구조 (JSON)

```text
resultCode       200 = 정상
resultMessage    "성공적으로 데이터를 가지고 왔습니다."
result
├─ pagging       { totCount, pageNum, pageSize }   ← 철자가 pagging (g 두 개). 상세 조회에는 없음
└─ youthPolicyList[]
```

XML(`rtnType=xml`)은 루트가 `<ResultVO>`이고 같은 구조다.

### 주요 필드

명세에는 60여 개 필드가 있다. 월급지도에 쓸 만한 것만 적는다 (전체 목록은 제공목록 페이지 참고).

| 필드 | 뜻 | 실제 값 / 주의 |
|---|---|---|
| `plcyNo` | 정책 번호 | `"20261104005400214719"` (20자리) |
| `plcyNm` | 정책 이름 | |
| `plcyKywdNm` | 정책 키워드 (쉼표 구분) | `"금리혜택,대출"`, `null`일 수 있음 |

| `aplyPrdSeCd` | 신청 기간 구분 코드 | `0057001` 특정기간, `0057002` 상시, `0057003` 마감 |

### Python 호출 예시

```python
import httpx

URL = 'https://www.youthcenter.go.kr/go/ythip/getPlcy'


def fetch_policies(api_key: str, zip_cd: str, page_size: int = 100) -> list[dict]:
    """시군구 코드 하나에 해당하는 청년정책을 모든 페이지에서 모은다."""
    policies: list[dict] = []
    page = 1
    while True:
        r = httpx.get(
            URL,
            params={
                'apiKeyNm': api_key,
                'rtnType': 'json',
                'zipCd': zip_cd,
                'pageNum': page,
                'pageSize': page_size,
            },
            timeout=10,
        )
        r.raise_for_status()  # 키가 틀리면 403 (6절)
        result = r.json()['result']
        policies += result['youthPolicyList']
        if len(policies) >= result['pagging']['totCount']:
            return policies
        page += 1
```

## 6. 오류

| 상황 | HTTP | 응답 본문 |
|---|---|---|
| 정상 | 200 | `resultCode` `200` |
| 키가 틀림 | **403** | `{"errorCode":"e001","errorMsg":"invalid api key."}` |
| 키를 안 보냄 | **400** | JSON이 아니라 **HTML 오류 페이지** |

금감원 API와 달리 오류를 HTTP 상태 코드로 돌려준다. `raise_for_status()`로 먼저 걸러야 HTML을 JSON으로 읽으려다 터지는 일이 없다.

## 7. 한계 (발표·질의응답 대비)

- **자격 조건 대부분이 자유 서술**이다. 소득 조건이 숫자(`0043002` 연소득)로 온 정책은 1,000건 중 4건뿐이고, `0043003`(기타) 150건은 실제 조건이 `earnEtcCn`·`addAplyQlfcCndCn` 문장 안에 있다 ("중위소득 150% 이하" 등). → 나이·지역은 코드로 거르고, 소득·자격은 LLM으로 요약하거나 "자격 확인 필요"로 보여 주는 방식을 고려한다. LLM이 자격을 잘못 판단할 수 있으므로 **신청 URL로 원문을 꼭 확인하게** 안내한다.
- `sprtTrgtAgeLmtYn` 같은 여부 플래그가 실제 값과 어긋나는 경우가 있다 (5절).
- 정책은 계속 등록·수정된다 (`frstRegDt`가 호출 전날인 정책도 있었다). 오래 저장해 두면 마감된 정책을 추천할 수 있다 → `aplyYmd`로 신청 기간이 지난 정책은 거른다.
- 응답의 `sprvsnInstPicNm`·`operInstPicNm`에 **공무원 담당자 실명**이 들어 있다. 화면·발표 자료·로그에 그대로 노출하지 않는다.
- 이용약관상 API 전용 조건(저장·출처 표기 등)은 아직 확인하지 못했다 (9절). 프로젝트 소개서 별첨 「활용한 외부 자원·출처」 표에는 출처를 적는다.

## 8. 월급지도에서 쓰는 방법 (제안 — 팀 논의 필요)

1. 사용자가 고른 시군구 코드(`lawd_codes.csv`)로 `zipCd` 필터 → 지역 정책만 가져온다.
2. 나이로 거른다 (`sprtTrgtMinAge` ≤ 나이 ≤ `sprtTrgtMaxAge`, 둘 다 `"0"`이면 제한 없음).
3. `lclsfNm=주거`, `금융･복지･문화`·`복지문화` 위주로 잔여액에 영향을 주는 정책(월세 지원, 중개수수료 지원, 자산형성 등)을 보여 준다. 중분류는 받아 온 뒤 코드에서 거른다 (4절).
4. `aplyPrdSeCd`가 `0057003`(마감)이거나 `aplyYmd`가 지난 정책은 뺀다.
