## 2. 인증키

- **키 값은 이 문서와 어떤 저장소에도 적지 않는다.** `backend/.env`에만 두고 팀원끼리는 직접 전달한다.
- 공공데이터포털은 계정 하나에 **일반 인증키 하나**를 주고, 그 키로 승인된 모든 API를 부른다. 세 API 모두 같은 키를 쓴다.
- 키 확인 위치: 공공데이터포털 로그인 → 마이페이지 → 데이터 활용 → Open API → 활용신청 현황 → 해당 API 상세 → "일반 인증키"
- 키는 Encoding / Decoding 두 형태로 보인다. 우리 팀 키는 영문 소문자·숫자 64자라 **두 값이 같다.** 특수문자(`+`, `/`, `=`)가 섞인 키라면 아래를 지킨다.
  - Python `httpx`·`requests`처럼 파라미터를 자동 인코딩하는 라이브러리에는 **Decoding 키**를 넣는다.
  - URL 문자열에 직접 붙일 때(브라우저)는 **Encoding 키**를 쓴다.
- 키가 틀리거나 아직 반영되지 않았으면 `SERVICE_KEY_IS_NOT_REGISTERED_ERROR`가 난다 (6절 참고).

```dotenv
# backend/.env (커밋 금지 — .gitignore에 등록됨, 형식은 backend/.env.example 참고)
DATA_GO_KR_SERVICE_KEY=<Decoding 키>
```

## 4. 요청 변수 (세 API 공통)

| 이름 | 필수 | 예시 | 설명 |
|---|---|---|---|
| `serviceKey` | 필수 | (인증키) | 공공데이터포털 인증키 |
| `LAWD_CD` | 필수 | `11110` | 지역코드. 법정동코드 10자리 중 앞 5자리(시군구). 예: 서울 종로구 = 11110 |
| `DEAL_YMD` | 필수 | `201512` | 계약년월 6자리 (YYYYMM) |

- `LAWD_CD` 값은 `backend/data/lawd_codes.csv`에서 찾는다 (아래 '지역코드표' 참고). 별도 API는 쓰지 않는다.
- 한 번 호출에 **시군구 하나 × 한 달**만 조회된다. 최근 N개월 시세를 보려면 월 수만큼 호출해야 한다 → SQLite 캐시 필수.

공개 페이지 표에는 없지만 실제로 동작하는 선택 변수:

| 이름 | 기본값 | 설명 |
|---|---|---|
| `pageNo` | 1 | 페이지 번호 |
| `numOfRows` | 10 | 한 페이지 건수. **기본 10건이라 꼭 지정해야 한다.** 1000으로 호출해 288건 전부 받는 것 확인 |
| `_type` | (XML) | `json`을 주면 JSON으로 응답. 단, **결과가 1건이면 `item`이 배열이 아니라 객체**로 오므로 파싱 시 주의 |

- 관악구 2026년 10월 한 달 건수: 단독·다가구 1,124건 / 연립다세대 386건 / 오피스텔 288건. 단독·다가구는 `numOfRows=1000`으로도 2페이지가 필요하다 → `totalCount`를 보고 페이지를 돌린다.

### 지역코드표 (`backend/data/lawd_codes.csv`)

- 출처: [행정표준코드관리시스템](https://www.code.go.kr/stdcode/regCodeL.do) → 법정동코드 전체자료 (파일 기준일 2026-10-01, 2026-11-11 다운로드)
- 만드는 법: 폐지 여부가 `존재`이고 10자리 코드의 뒤 5자리가 `00000`인 행(시군구)만 골라 앞 5자리를 `LAWD_CD`로 사용. 시도 행은 제외
- 열: `lawd_cd`, `sido`, `sigungu`, `full_name`, `selectable`
- 269행 중 **선택 가능 255개**. 일반구가 있는 시 14곳(수원·성남·안양·부천·안산·고양·용인·화성 등)은 `selectable=false`
  - 실거래가 API는 **구 단위 코드**로만 결과를 준다. 수원시 `41110` → 0건, 수원시 장안구 `41111` → 21건 (오피스텔, 2026년 10월)
  - 드롭다운에는 `selectable=true`만 보여 준다
- 세종특별자치시는 시군구가 없어 `36110` 하나 (79건 확인)
- `북구`, `중구`처럼 이름이 겹치는 곳이 많으므로 화면과 로그에는 `full_name`을 쓴다

#### 광주·전남 통합 주의

- 이 파일에서 광주광역시·전라남도는 **전남광주통합특별시(앞자리 `12`)**로 바뀌어 있고, 옛 코드(`29xxx`, `46xxx`)는 `폐지`로 표시된다.
- 실거래가 API도 새 코드만 받는다. 광주 북구 연립다세대로 확인한 결과, 옛 코드 `29170`은 2026년 1~10월 모두 0건이고 새 코드 `12300`은 같은 기간 과거 달까지 결과가 나온다.
- 따라서 **최신 코드표만 쓰면 된다.** 행정구역이 또 바뀌면 같은 방법으로 파일을 다시 받아 표를 갱신한다.

## 5. 응답

### 공통 구조 (XML)

```xml
<response>
  <header><resultCode>000</resultCode><resultMsg>OK</resultMsg></header>
  <body>
    <items><item>...</item> ...</items>
    <numOfRows>1000</numOfRows><pageNo>1</pageNo><totalCount>288</totalCount>
  </body>
</response>
```

### 필드 (실제 응답 기준)

| 필드 | 뜻 | 단독·다가구 | 연립다세대 | 오피스텔 | 비고 |
|---|---|:-:|:-:|:-:|---|
| `sggCd` | 시군구 코드 | O | O | O | `LAWD_CD`와 같음 |
| `sggNm` | 시군구명 | | | O | |
| `umdNm` | 법정동명 | O | O | O | 예: 신림동, 봉천동 |
| `jibun` | 지번 | | O | O | 단독·다가구는 없음 |
| `mhouseNm` | 건물명 | | O | | |
| `offiNm` | 단지명 | | | O | 이름이 없으면 `(701-20)`처럼 지번이 들어감 |
| `houseType` | 주택유형 | O | O | | `단독`/`다가구`, `연립`/`다세대` |
| `buildYear` | 건축년도 | O | O | O | |
| `floor` | 층 | | O | O | |
| `excluUseAr` | 전용면적(㎡) | | O | O | 1인 가구 필터 기준 |
| `totalFloorAr` | 계약면적(㎡) | O | | | 단독·다가구는 전용면적 대신 이 값 |
| `dealYear` `dealMonth` `dealDay` | 계약일 | O | O | O | |
| `deposit` | 보증금(만원) | O | O | O | **쉼표 포함 문자열** 예: `14,000` |
| `monthlyRent` | 월세(만원) | O | O | O | `0`이면 전세 |
| `contractType` | 신규/갱신 | O | O | O | 빈 값(공백 한 칸) 많음 |
| `contractTerm` | 계약기간 | O | O | O | 예: `26.10~27.10`, 빈 값 많음 |
| `preDeposit` `preMonthlyRent` | 갱신 전 보증금·월세 | O | O | O | 갱신 계약일 때만 |
| `useRRRight` | 계약갱신청구권 사용 | O | O | O | `사용` 또는 빈 값 |

- 빈 값은 빈 문자열이 아니라 **공백 한 칸(`" "`)** 으로 온다 → `strip()` 후 처리.
- 숫자는 쉼표를 지우고 정수/실수로 바꾼다. 금액 단위는 **만원**.
- 시군구 코드·지번은 개별 거래 정보이므로 화면에는 법정동 단위 집계값만 보여 준다.

### 응답 예시 (오피스텔, 1건, 키 제거)

요청:
```
GET https://apis.data.go.kr/1613000/RTMSDataSvcOffiRent/getRTMSDataSvcOffiRent
    ?serviceKey=<KEY>&LAWD_CD=11620&DEAL_YMD=202610&numOfRows=1&pageNo=1
```

응답 `item`:
```xml
<item>
  <buildYear>1998</buildYear><contractTerm>26.10~27.10</contractTerm><contractType>신규</contractType>
  <dealDay>24</dealDay><dealMonth>10</dealMonth><dealYear>2026</dealYear>
  <deposit>300</deposit><excluUseAr>15.28</excluUseAr><floor>5</floor>
  <monthlyRent>55</monthlyRent><preDeposit> </preDeposit><preMonthlyRent> </preMonthlyRent>
  <sggCd>11620</sggCd><sggNm>관악구</sggNm><umdNm>봉천동</umdNm><useRRRight> </useRRRight>
</item>
```
→ 봉천동 전용 15.28㎡ 오피스텔, 보증금 300만 원 / 월세 55만 원 신규 계약.

### Python 호출 예시

```python
import os
import httpx

URL = "https://apis.data.go.kr/1613000/RTMSDataSvcOffiRent/getRTMSDataSvcOffiRent"
params = {
    "serviceKey": os.environ["DATA_GO_KR_SERVICE_KEY"],
    "LAWD_CD": "11620",   # 서울 관악구
    "DEAL_YMD": "202610",
    "numOfRows": 1000,
    "pageNo": 1,
}
r = httpx.get(URL, params=params, timeout=10)
r.raise_for_status()
xml_text = r.text  # 6절의 오류 형식도 HTTP 200으로 올 수 있으므로 본문으로 판단
```

## 6. 오류와 빈 결과

| 상황 | 실제 응답 | 처리 |
|---|---|---|
| 정상 | `<resultCode>000</resultCode>` | |
| 키 오류·미등록 | **다른 형식**: `<OpenAPI_ServiceResponse><cmmMsgHeader><errMsg>SERVICE_KEY_IS_NOT_REGISTERED_ERROR</errMsg><returnReasonCode>30</returnReasonCode>` | 최상위 태그가 `response`가 아니면 오류로 처리하고 로그 |
| `LAWD_CD` 누락 | 오류 없이 `resultCode 000`, `totalCount 0` | **조용히 빈 결과가 오므로 호출 전에 값 검증 필수** |
| 아직 오지 않은 달 (`202701`) | `resultCode 000`, `totalCount 0` | 빈 결과로 처리 |

- 결과가 0건이면 "데이터 없음"으로 보여 주고 사용자 입력을 받는다. 오류와 0건을 구분해서 화면에 보여 준다.

## 6. 월급지도에서 쓰는 방법 (설계)

1. 사용자가 고른 지역(시군구) → `LAWD_CD`로 변환 (위치정보는 받지 않음)
2. 최근 6개월(`DEAL_YMD` 6개)을 세 유형 모두 조회 → SQLite에 캐시
3. 월세 계약만 남기고(`monthlyRent` 0인 전세는 제외), 면적 33㎡(약 10평) 이하로 걸러 1인 가구 기준을 맞춘다. 연립다세대·오피스텔은 `excluUseAr`, 단독·다가구는 `totalFloorAr` 사용
4. 월세 **중앙값**과 표본 수를 계산 (평균은 큰 평형·고가 매물에 끌려가므로 쓰지 않음)
5. 결과에 출처 "국토교통부 전월세 실거래가"와 신뢰도 **추정**을 표시. 사용자가 월세를 직접 입력하면 그 값이 우선(신뢰도 **사용자 입력**)

## 7. 한계 (발표·질의응답 대비)

- **저가 원룸 누락 가능성**: 전월세 신고제는 보증금 6천만 원 초과 또는 월세 30만 원 초과 계약만 신고 대상이라, 아주 싼 원룸은 데이터에 덜 잡힐 수 있다.
- **고시원·원룸텔 없음**: 법상 주택이 아니라 실거래가 대상이 아니다 → 사용자 입력으로 처리.
- **표본 부족 지역**: 시군구·월 단위로 거래가 몇 건 안 되는 곳이 있다. 표본 수가 적으면 화면에 "표본 N건"을 함께 보여 준다.
- **주소 정밀도**: 단독·다가구는 지번 일부만, 연립다세대·오피스텔은 동·호가 없으므로 시군구(또는 법정동) 단위로만 집계한다.
