# AI 활용내역 — 월급지도 (첫월급연구소)

과제 제출서 「AI 활용내역」에 붙여 넣는 글입니다. 대회 기준(첨부3 제4조)의 네 항목 순서이고 3,000자 이내입니다.
아래 「상세 기록」은 이 글의 근거입니다 (제출 글에는 넣지 않음).

---

## 제출 글

**① 활용 AI 모델·도구**
[서비스] Claude Sonnet 5.5 API(공고 조건 정리, 이미지 글자 읽기, 청년 정책 조건 정리, 비교 리포트 작성), Claude Haiku 5.5 API(리포트 검토). 요청이 거절되면 서버가 대체 모델로 자동 전환한다. LangGraph 1.x(에이전트 흐름).
[개발] Claude Code(Claude Opus 5.5, 코드 작성·테스트·코드 리뷰), Claude(기획), Claude Fable 5.2(설계 조언·코드 검토), GPT(코드 리뷰).

**② AI 활용 범위와 팀의 기여**
원칙은 '숫자는 코드, 문장은 AI'다. AI는 형식이 제각각인 공고(글·PDF·엑셀·이미지)와 청년 정책 원문을 읽어 정리하고 결과를 문장으로 설명한다. 세금·4대보험·매달 남는 돈과 결론은 팀이 설계한 코드가 계산한다. AI는 리포트에 금액을 직접 쓰지 못하고 코드가 계산값을 넣는다.
팀은 문제 정의(첫 월급의 '실제로 남는 돈'), 계산 규칙(간이세액표·4대보험 요율), 에이전트 흐름, 개인정보 마스킹 정책, 프롬프트 규칙을 정했다. 'AI가 읽은 조건만으로 정책을 빼지 않고 맞는지만 표시한다'는 판단 규칙도 팀이 정했다. 코드 초안은 대부분 Claude Code가 썼다. 팀이 이슈 단위로 지시하고 PR마다 실행해 확인한 뒤 병합했다.

**③ API·외부 데이터·오픈소스**
고용24, 온통청년, 국토교통부 전월세 실거래가, 금융감독원 금융상품한눈에 API, 근로소득 간이세액표(2026. 2. 27. 개정), 2026년 4대보험 요율 고시. 오픈소스는 FastAPI, LangGraph, PyMuPDF, Next.js, React 등이다. 상세 출처·라이선스는 소개서 별첨 「활용한 외부 자원·출처」 표에 적었다.

**④ 검증 및 한계 대응**
- 검증: AI는 값마다 원문 인용을 함께 낸다. 코드는 그 인용이 원문에 실제로 있는지 대조하고 없으면 버린다. 계산은 사용자가 정리된 표를 확인한 뒤에만 한다. 리포트는 Haiku 검토 뒤에도 금액·사실 문제가 남으면 숨긴다. 백엔드 테스트 700여 개를 PR마다 돌린다. 계산 엔진 테스트의 기댓값은 간이세액표와 고시 원문으로 직접 만든다. 청년 정책 30개는 원문과 하나씩 대조했다(지어낸 인용 0개, 27개 정확).
- 바로잡은 오류와 보완:
  · AI가 만든 세액표가 2024년판이었다 → 법령 원문과 대조해 2026년판으로 바꾸고 표가 원문과 같은지 테스트로 고정했다.
  · 실제 Claude로 돌렸을 때 '식대 별도 지급'을 놓쳐 남는 돈이 약 16만원 적게 나왔다 → 원문 인용에 '별도'가 있는지를 코드가 보고 판정하게 했다.
  · 정책 실험에서 AI가 '신규 가입 중단'을 놓쳤다 → 주의할 점을 따로 뽑아 정책마다 화면에 보여 준다.
- 개인정보: 시연과 테스트에는 가상 공고만 썼다. 글·PDF·엑셀은 AI에 보내기 전에 코드가 연락처·주민번호·이름·상세 주소를 가린다. 이미지는 글자를 읽기 전에는 가릴 수 없다. 그래서 회사가 공개한 공고 캡처만 올리고 이름·연락처는 가리도록 화면에 늘 안내한다. 파일 원본과 회원 정보는 저장하지 않는다. 나이는 정책을 거르는 데만 쓰고 무주택·세대주 답은 AI에 보내지 않는다.
- 남은 한계: 주소를 받지 않아 출퇴근 시간은 판단하지 않고 교통비는 사용자가 넣는다. 월세 시세·정책·금리는 조회한 날 기준이다. 정책 요약에도 빠진 조건이 있을 수 있어(30개 중 3개 오류) 신청 전에 공고문을 확인하라고 안내한다.

### 서비스 안에서 AI를 쓰는 곳 (LangGraph 노드)

| 노드 | AI | 하는 일 | 왜 AI인가 / 안전장치 |
|---|---|---|---|
| `route_input` → 파일 읽기 | Sonnet 5.5 (이미지·글자 없는 PDF 쪽만) | 이미지 공고의 글자를 옮겨 적음 | PDF 글자 쪽은 PyMuPDF, 엑셀은 openpyxl로 AI 없이 읽음. 하루 장 수 상한 |
| `normalize` | Sonnet 5.5 | 공고 글 → 비교표 (값 + 원문 인용) | 공고 형식이 제각각이라 규칙만으로 못 읽음. 보내기 전 개인정보 마스킹, 인용을 코드가 원문과 대조 |
| `confirm_table` | — | 사용자가 표를 확인·수정 (interrupt) | AI 결과를 사람이 확인한 뒤에만 계산 |
| `check_missing` | — | 계산을 막는 빈 값을 되묻기 | 질문 목록은 코드가 정함 |
| `get_rent` ∥ `get_local_support` | — | 실거래가·청년 정책 조회 | 공공데이터 API |
| `calculate` | — | 세후 월급·매달 남는 돈·손익분기 연봉 | 순수 Python + 테스트 |
| `write_report` | Sonnet 5.5 | 결과를 회사별 한 줄로 설명 | 금액은 자리표시로만, 코드가 채움 |
| `verify_report` | Haiku 5.5 + 코드 검사 | 금액 귀속·없는 사실·권유 검사 | 문제가 있으면 다시 쓰기(쓰기 최대 3번 = 다시 쓰기 2번), 금액·사실 문제가 남으면 숨김 |
| 정책 조건 읽기 (`GET /sessions/{id}/policy-terms`, 그래프 밖) | Sonnet 5.5 (구조화 출력) | 플랜에 보이는 청년 정책 원문 → 지원 내용·주의·금액 구절·신청 조건 | 공개 정책 글만 보냄(사용자 정보 없음). 인용을 원문과 대조, 정책마다 한 번만 읽고 저장, 읽을 정책은 서버가 세션 플랜에서 고름. 조건으로 정책을 빼지 않음 |
