# AI 활용내역 — 월급지도 (첫월급연구소)

과제 제출서 「AI 활용내역」에 붙여 넣는 글입니다. 대회 기준(첨부3 제4조)의 네 항목 순서이고 3,000자 이내입니다.
아래 「상세 기록」은 이 글의 근거입니다 (제출 글에는 넣지 않음).

---

## 제출 글

**① 활용 AI 모델·도구**
[서비스] Claude Sonnet 5.5 API(공고 글·이미지·PDF에서 조건 정리, 이미지 글자 옮겨 적기, 비교 리포트 작성), Claude Haiku 5.5 API(리포트 검토). LangGraph 1.x(에이전트 흐름·사용자 확인 대기).
[개발] Claude Code(코드 작성·리팩터링·테스트·코드 리뷰), Claude(claude.ai, 기획서·기술 스택 정리), Claude Fable(최종 검수), GPT 계열 도구(화면 개선 의견 일부).

**② AI 활용 범위와 팀의 기여**
- 서비스: AI는 형식이 제각각인 공고(붙여넣기·PDF·엑셀·이미지)를 같은 비교표로 정리하고, 빈 값을 되묻고, 결과를 문장으로 설명한다. 세금·4대보험·매달 남는 돈·손익분기 연봉은 AI가 아닌 코드가 계산한다. AI는 리포트에 금액을 직접 쓰지 못하고 자리표시만 쓰며, 코드가 계산값을 채운 뒤 검사한다.
- 팀: 문제 정의(첫 월급의 '실제로 남는 돈'), 계산 규칙(간이세액표·4대보험 요율), 에이전트 흐름과 '숫자는 코드, 문장은 AI' 원칙, 개인정보 마스킹 정책, 프롬프트 규칙을 직접 정했다. 코드 초안 대부분은 Claude Code가 썼고, 팀이 이슈를 하루 단위로 나눠 지시하고 PR마다 서로 리뷰·실행 확인한 뒤 병합했다.

**③ API·외부 데이터·오픈소스**
고용24 OpenAPI(재직자 훈련과정), 온통청년 청년정책 API, 국토교통부 전월세 실거래가 API(공공데이터포털, 근무지 월세 시세), 금융감독원 금융상품한눈에 API(적금 기본금리), 소득세법 시행령 근로소득 간이세액표(2026. 2. 27. 개정), 2026년 4대보험 요율 고시, 법정동코드(행정표준코드관리시스템). 오픈소스: FastAPI, LangGraph·LangChain Core, PyMuPDF, openpyxl, Next.js, React, Tailwind CSS, shadcn/ui, Sentry SDK(셀프호스팅 GlitchTip). 시연은 가상 공고만 쓴다. 상세 출처·라이선스는 소개서 별첨 「활용한 외부 자원·출처」 표 참조.

**④ 검증 및 한계 대응**
- 검증: AI가 낸 값마다 원문 인용을 함께 받아 코드가 원문에 있는지 대조하고, 인용 속 숫자를 코드가 다시 읽는다. 모든 값에 확인/추정/사용자 입력을 표시하고, 표는 사용자가 확인·수정한 뒤에 계산한다. 리포트는 금액 자리표시 검사와 Haiku 검토를 거쳐 최대 3번까지 다시 쓰고, 통과하지 못하면 숨긴다. 백엔드 테스트 700여 개를 PR마다 돌리고, 계산 엔진 테스트의 기댓값은 간이세액표·고시 원문으로 직접 만든다.
- 바로잡은 오류: AI가 만든 세액표가 2024년판이라 법령 원문과 대조해 2026년판 자녀 공제로 고쳤다. 실제 Claude가 '식대 별도 지급'을 비워 남는 돈이 약 16만원 적게 나와, 원문 인용으로 코드가 판정하게 했다. 리포트 검토가 맞는 글을 떨어뜨리고 세후 월급을 다른 연봉에 붙이는 실수가 잦아, 판정 형식과 코드 검사를 추가했다. PDF가 공백으로 약 3배 부풀어 글자 제한에 걸린 문제를 실제 인쇄 PDF로 재현해 고쳤다. AI가 쓴 이메일 마스킹 규칙이 긴 글에서 멈추는 것을 테스트로 찾아 고쳤다.
- 개인정보: AI에 보내기 전 전화번호·이메일·주민번호·생년월일·이름 등을 가리고, 로그인 없이 세션이 끝나면 보관하지 않는다. 오류 추적에도 요청 본문을 보내지 않는다.
- 남은 한계: 개인정보를 줄이려고 사용자 주소를 받지 않고 지도·경로 API도 쓰지 않아 출퇴근 가능 여부와 시간은 판단하지 않는다. 대신 공고마다 '지금 집에서 다닐 수 있음'을 사용자가 고르고 교통비를 직접 넣는다(비우면 0원으로 계산하고 더 들 수 있다고 표시). 월세 시세·청년 정책·적금 금리는 조회일 기준이라 신청 전 원문 확인을 안내한다.

## 상세 기록

### 서비스 안에서 AI를 쓰는 곳 (LangGraph 노드)

| 노드 | AI | 하는 일 | 왜 AI인가 / 안전장치 |
|---|---|---|---|
| `route_input` → 파일 읽기 | Sonnet 5.5 (이미지·글자 없는 PDF 쪽만) | 이미지 공고의 글자를 옮겨 적음 | PDF 글자 쪽은 PyMuPDF, 엑셀은 openpyxl로 AI 없이 읽음. 하루 장 수 상한 |
| `normalize` | Sonnet 5.5 | 공고 글 → 비교표 (값 + 원문 인용) | 공고 형식이 제각각이라 규칙만으로 못 읽음. 보내기 전 개인정보 마스킹, 인용을 코드가 원문과 대조 |
| `confirm_table` | — | 사용자가 표를 확인·수정 (interrupt) | AI 결과를 사람이 확인한 뒤에만 계산 |
| `check_missing` | — | 계산을 막는 빈 값을 되묻기 | 질문 목록은 코드가 정함 |
| `get_rent` ∥ `get_local_support` | — | 실거래가·청년 정책 조회 | 공공데이터 API |
| `calculate` | — | 세후 월급·매달 남는 돈·손익분기 연봉 | 순수 Python + 테스트 |
| `write_report` | Sonnet 5.5 | 결과를 회사별 한 줄로 설명 | 금액은 자리표시로만, 코드가 채움 |
| `verify_report` | Haiku 5.5 + 코드 검사 | 금액 귀속·없는 사실·권유 검사 | 실패하면 다시 쓰기(최대 3번), 끝내 실패하면 숨김 |
